
## 1. Python의 디자인 패턴

* 고전적인 디자인 패턴 중 일부는 **Python에서는 필요하지 않다.**
  * 단, 그 이유는 **해당 디자인 패턴이 Python 내부적으로 구현되어 있기** 때문이다.
* 디자인 패턴은 **발명** 이 아닌 **발견** 되는 것이다.

## 2. Python의 디자인 패턴의 분류

Python의 디자인 패턴은 대표적으로 **생성, 구조, 행동 패턴** 으로 분류된다.

| 구분              | 설명                                       |
|-----------------|------------------------------------------|
| 생성 (creational) | **객체 인스턴스화 시 복잡성을 추상화** 하기 위한 패턴         |
| 구조 (structural) | 인터페이스를 복잡하게 하지 않으면서, **기능을 확장** 하기 위한 패턴 |
| 행동 (behavioral) | 객체 간의 협력/통신, 런타임 중 인터페이스의 형태 등에 대한 패턴    |
| 기타              | 생성, 구조, 행동 패턴을 **확장 또는 변형시킨 추가 패턴**      |
